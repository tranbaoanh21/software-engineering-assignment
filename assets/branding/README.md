# Smart E-mobility Hub — web logo assets

Original **vector SVG** set featuring an **electric scooter**, a campus map pin, a road, and a charging/lightning motif. No automobile imagery.

Files:
- `logo-horizontal.svg` — primary horizontal logo, transparent background.
- `logo-compact.svg` — horizontal logo without subtitle, transparent background.
- `logo-icon.svg` — standalone scalable icon, transparent background.
- `logo-horizontal.png` / `logo-compact.png` / `logo-icon.png` — transparent PNG exports.
- `logo-horizontal.webp` — WebP export.
- `icon-32.png`, `icon-64.png`, `icon-192.png`, `icon-512.png` — square icon with an opaque pale background (favicons/PWA).
- `favicon.ico` — website favicon.

Primary colors:
- Teal: `#0F766E`
- Navy: `#102A43`
- Background: `#F3F8FC`

Use with React / Next.js:
```tsx
<img src="/assets/logo-compact.svg" alt="Smart E-mobility Hub" width="320" height="80" />
```

Next.js App Router favicon: copy `favicon.ico` to `app/favicon.ico`. Or set `<link rel="icon" href="/assets/logo-icon.svg">`.

These are genuine, editable vector SVG illustrations produced for the project, not image-traced originals. Verify brand authorization and do not imply official university endorsement without permission.
