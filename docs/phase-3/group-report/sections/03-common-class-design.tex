\paragraph{Quy tắc đọc bảng phương thức}
Phương thức có session dùng AccessService kiểm tra quyền/phạm vi hiện hành; command kiểm tra lại trong transaction. Query chỉ đọc DTO an toàn. Command áp dụng requestId, version, audit/receipt và rollback theo Mục~\ref{sec:p3-common-processing}; lỗi theo hợp đồng HTTP dùng chung. Tham số và kiểu trả về nằm ở signature, phần đặc tả chỉ nêu điều kiện/tác động riêng. Entity chỉ đổi đối tượng trong bộ nhớ; service lưu thay đổi. Transition/input không hợp lệ bị từ chối trước khi ghi; InTx dùng transaction caller, không tự commit.
