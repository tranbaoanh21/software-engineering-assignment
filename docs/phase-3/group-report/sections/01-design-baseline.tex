\section{Kiến trúc hệ thống}
\subsection{Phương án kiến trúc và công nghệ}
SEMH sử dụng \textbf{modular monolith kết hợp layered architecture}: một backend chứa GEN và bảy module nghiệp vụ. Mỗi module tách phần tiếp nhận yêu cầu, application service, miền nghiệp vụ và adapter lưu trữ/tích hợp; các module dùng chung PostgreSQL và phối hợp qua hợp đồng công khai.

Hệ thống gồm 23 use case và bốn vai trò STU/OPR/MNT/ADM. Nguồn IoT giả lập gửi trạng thái vào backend; Leaflet hiển thị Hub trên nền bản đồ từ EXT-MAP.
