\section{Thiết kế theo phân hệ và use case}\label{sec:phase2-by-uc}

Mỗi phân hệ bắt đầu bằng bộ mockup dùng chung, sau đó lần lượt trình bày từng use case cùng sequence diagram, activity diagram và dẫn chiếu state chart liên quan. Sequence diagram chỉ được bổ sung lifeline kỹ thuật sau khi nhóm xác định rõ trách nhiệm thiết kế; actor và external system phải giữ theo Phase 1. Activity diagram có thể dùng swimlane để phân biệt actor, SEMH và external system.
