\subsubsection{Tổ chức package và chiều phụ thuộc}
\FinalImplementationFigure{0.73\textheight}{backend-packages}
  {Package Diagram toàn hệ thống SEMH}{fig:p3-backend-packages}

GEN và bảy phân hệ chạy trong cùng một ứng dụng NestJS. Mũi tên nét đứt trỏ về package được sử dụng. Presentation gọi Application, Application dùng luật và thực thể của Domain. Infrastructure hiện thực hợp đồng Application hoặc gọi service khi chạy tác vụ nền. Mỗi phân hệ truy cập dữ liệu của phân hệ khác qua hợp đồng của owner.
